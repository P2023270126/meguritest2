MEGURI Studio — 品牌企劃手冊風格

這是一個重新編排版面及互動方式的獨立版本。
參考 Superr 的紙張感、柔和展示字體、傾斜實物攝影、手繪線條、外框按鈕及品牌頁尾。
保留 MEGURI 桃紅品牌識別，採用暖白紙張底色、深色文字和本機 serif 展示字體。
沒有加入任何新服務、價格、客戶案例、客戶推薦或宣傳聲稱。

版面
- 首頁：單張大型傾斜活動圖片，搭配紙膠帶及簡單車輛線條裝飾。
- What We Do：另外兩張原有圖片以企劃手冊圖片跨頁方式呈現，配合三項服務價值。
- Our Formats：七款車型可點選切換大型圖片及描述，支援鍵盤方向鍵、Home 和 End。
  手機選項橫向排列，左右滑動即可找到其餘車型。
  車型圖片可點擊放大；Escape 或關閉按鈕可離開。
  網址 ?format=1 至 ?format=7 可直接指定展示車型。
  未啟用 JavaScript 時仍會顯示全部七款圖片及描述。
- Use Cases：改成兩欄線條清單，手機以一欄顯示。
- Enquiry：沿用原有表格設計、所有欄位、Formspree 及提交流程。
- 頁尾：桃紅品牌收尾，手機底部固定 WhatsApp 和 e-Form。

上載方法
1. 解壓 MEGURI-Studio.zip。
2. 上載 index.html 及 images 資料夾到現有 GitHub Pages 網站，取代同名檔案。
3. 保留原有 thank-you.html，這個套件沒有修改或取代它。
4. 若只下載首頁 HTML，請確保檔名為 index.html 並且與 images 同層。
5. 更新後用 Ctrl+F5 或私人瀏覽確認新版。

新增廣告彈窗
- 圖片載入後等 1 秒顯示。
- 正方形展示區，完整顯示 images/hero-1.jpg，不裁走圖片內容。
- 顯示 5 秒後自動關閉，設有倒數及右上角 ×。
- Escape、點擊背景或點擊廣告前往查詢區亦會關閉。
- 每個分頁瀏覽工作階段只顯示一次；重新整理不會重複彈出。
- 正在填表或已有圖片檢視對話框時不會彈出。
- 更換廣告圖片：修改 id="promo-image" 的 src，並配合調整圖片尺寸屬性。
- 關閉秒數：修改 PROMO_SECONDS；首次延遲：修改 PROMO_DELAY_MS。
- 彈窗邏輯已測試；實際瀏覽器畫面仍待驗證。
